# 정식 서버 이전 준비 (2026-10-09)

사용자 결정: 미리보기 사진 문제(ngrok 무료 경고 화면)는 ③ 정식 서버 이전으로 해결한다. 어제 확인한 MW 서버에 호스팅을 만들고, 개설 방법은 사용자가 나중에 묻는다.
아래는 호스팅을 고를 때·만든 뒤 필요한 조건이다. 서버 종류가 확정되면 이 문서를 기준으로 이전한다.

## 1. 호스팅이 꼭 지원해야 하는 것
| 항목 | 이유 |
|---|---|
| Node.js 실행(20 이상, 지금 PC는 24.14.0) | 써보니는 Next.js 16 서버 프로그램이다. PHP 전용 웹호스팅에서는 실행할 수 없다(확인 필요) |
| 프로그램이 계속 켜져 있는 환경(VPS·서버 호스팅 또는 Node 상시 실행 지원) | `npm start`로 띄운 서버가 꺼지지 않아야 한다 |
| 파일을 저장할 디스크(최소 1GB 권장) | DB 파일 `dev.db`(현재 0.6MB)와 상품 사진 `runtime-data/uploads`(현재 205MB)가 서버 디스크에 남아야 한다 |
| 네이티브 모듈 설치 | `better-sqlite3`, `sharp`가 서버 운영체제에 맞게 설치돼야 한다 |
| 도메인 연결 + HTTPS 인증서 | 카카오 미리보기·공유와 보안 쿠키에 필요하다 |

## 2. 옮길 것
- 코드: GitHub 저장소 `gate0/market-ui` 브랜치(또는 main 합친 뒤)
- 데이터: `app/dev.db`(백업 기능으로 복사), `app/runtime-data/`(사진, 수수료 설정. 거래 설정 파일은 아직 없음)
- 비밀값: `app/.env`의 `SESSION_SECRET`, `ADMIN_KEY`, `DATABASE_URL`
  - 화면이나 채팅에 쓰지 않고 서버에 직접 옮긴다.
  - `SESSION_SECRET`을 바꾸면 기존 로그인과 암호화한 계좌·주소를 읽을 수 없으므로 같은 값을 써야 한다.

## 3. 이전 순서(예정)
1. 서버에 Node.js와 git을 설치하고 저장소를 받는다. `npm ci`와 `npm run build`를 실행한다.
2. 이 PC 서버를 잠시 멈추고 DB와 사진을 백업해 서버로 복사한다. 그 뒤에는 이 PC에 새 데이터가 생기지 않게 한다.
3. 서버에 `.env`를 넣고, 프로그램을 상시 실행 관리자(pm2 등)로 띄운다.
4. 도메인과 HTTPS를 연결하고, 앞단 프록시(nginx 등)에서 3000번으로 넘긴다.
5. 브라우저로 확인한다(PC·휴대폰, 모든 화면, 거래 시험은 복사 데이터). 카카오톡 미리보기 사진도 확인한다.
6. ngrok 링크 대신 새 주소를 베타테스터에게 안내한다. 이전에 공유된 ngrok 링크는 열리지 않게 된다.

## 4. 사용자에게 필요한 것
- 호스팅 종류(Node 실행 가능 여부)와 접속 정보. 접속 비밀번호는 채팅에 쓰지 않고 사용자가 직접 입력한다.
- 쓸 도메인
