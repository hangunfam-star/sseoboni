# 후기·등급·남은 작업 검토와 제안 (2026-10-09)

사용자가 준 기획(후기 1~10점·문구, 써린이~고수 등급, 후기 3종 분리, 판매자 채널, 써보니 평균 금액, 남은 작업 7개)을 검토한 결과와 제안이다. 구현 전 단계다.

## 1. 후기
- 문구는 점수에 따라 바뀌게 한다. 7점 이상은 칭찬 문구, 4점 이하는 아쉬운 문구(설명과 달라요, 응답이 늦어요)를 보여 준다. 낮은 점수에 칭찬 문구만 있으면 후기를 믿을 수 없기 때문이다.
- 문구는 쓰는 방향에 맞춰 따로 둔다.
  - 구매자 → 판매자: 배송이 빨라요, 설명과 같아요, 구성품이 다 있어요, 친절해요
  - 판매자 → 구매자: 구매확정이 빨라요, 반납이 깨끗해요, 기한을 지켜요, 약속을 잘 지켜요
  - 써보니 후기: 써보고 사니 안심돼요, 실물이 사진과 같아요, 써보고 안 맞아 돌려보냈어요
- 예시 문장은 누르면 입력칸에 들어가고, 그 자리에서 고칠 수 있게 한다.
- 직접 쓰는 후기에도 채팅과 같은 연락처·계좌 차단을 적용한다.
- 서로 쓰는 후기는 동시에 공개한다. 둘 다 썼거나 7일이 지나면 함께 보인다. 상대 후기를 보고 보복성 후기를 쓰는 것을 막기 위해서다.
- 후기는 거래 완료 후 14일 안에만 쓸 수 있다. 3일째에 한 번 다시 알린다.

## 2. 등급 (구매자·판매자 따로)
- 기준: 완료 거래 수와 받은 평균 점수
- 예시 단계(수치는 확정 필요)

| 등급 | 조건 예시 |
|---|---|
| 써린이 | 완료 거래 0~2건 |
| 하수 | 3~9건 |
| 중수 | 10~29건, 평균 7점 이상 |
| 고수 | 30건 이상, 평균 8점 이상, 확정 분쟁 0건 |
| 레벨 | 각 등급 안에서 Lv.1~5로 세분해 오르는 재미를 준다 |

- 등급 부풀리기 방지
  - 같은 상대와의 거래는 한 달에 1건만 센다.
  - 5,000원 미만 거래는 0.5건으로 센다.
  - 확정 분쟁이 생기면 한 단계 내린다.
- 등급은 판매자 채널, 상품 상세의 판매자 줄, 채팅 상단에 보여 준다.

## 3. 판매자 채널
- 보여 줄 내용
  - 등급, 받은 후기(구매자 → 판매자), 써보니 후기, 판매 중 상품
  - "써본 사람 12명 중 9명 구매" 같은 실제 숫자
  - 써보니 평균 금액
- 주소는 /sellers/판매자id로 한다. 상품 상세와 채팅에서 판매자 이름을 누르면 이동한다.
- 당근 후기는 "당근 후기 64개(외부)"처럼 링크만 둔다. 써보니 점수에는 섞지 않는다.

## 4. 써보니 평균 금액
- 해석: "써보기 체험비 평균"으로 해석했다. 다른 뜻이면 확인이 필요하다.
- 기준 순서
  1. 같은 모델이 5건 이상이면 그 모델의 평균을 쓴다.
  2. 모자라면 같은 상품군(카테고리)의 평균을 쓴다.
  3. 그것도 모자라면 "데이터 부족"으로 표시한다.
  - 판매자 채널에는 그 판매자의 평균을 따로 보여 준다.
- 쓰는 곳
  - 상품 상세: "이 상품군 24시간 평균 체험비 2,100원"
  - 판매자가 체험비를 정할 때 추천 금액. 데이터가 쌓이면 지금의 상품가 0.7% 공식을 실제 평균으로 바꾼다.

## 5. 남은 작업 검토

### 구매 흐름(상태)
주문 → 입금 대기 → 입금 확인 → 발송 → 수령(써보기 시작) → (연장) → 구매확정 또는 반납 → 반납 확인 → 정산 → 후기
- 주문할 때 배송지를 받는다. 판매자는 입금 확인 뒤에만 배송지를 볼 수 있다.
- 상태가 바뀔 때마다 그 상품의 채팅방에 시스템 메시지로 남긴다. 문자나 푸시 알림 없이도 채팅방이 주문 기록 역할을 한다.

### 결제(무통장)
- 입금자 확인용 고유 입금자명을 붙인다. 예: 닉네임+숫자 4자리.
- 입금 기한을 24시간으로 두고, 지나면 주문을 자동 취소한다.
- 은행 연동이 없으므로 운영자가 입금 확인 버튼을 눌러 처리한다.
- 계좌는 주문을 만든 뒤 주문 화면에만 보여 준다.
- 법·규제 확인 필요: 플랫폼이 구매자 돈을 받아 두었다가 판매자에게 보내는 구조는 전자금융거래법(결제대행·선불)과 전자상거래법(구매안전서비스·에스크로)에 해당할 수 있다. 실제 운영 전에 법률·세무 확인이 필요하다. 베타 시험은 소액·지인 대상이나 실제 돈 없이 하는 방법을 권장한다.

### 써보기 연장
- 구매자가 이미 상품 가격 전액을 미리 냈으므로, 연장해도 추가 입금은 필요 없다. 다음 구간 체험비와의 차액만큼 환불금이 줄어든다.
- 연장은 끝나기 전에만 할 수 있고, 판매자가 정한 가장 긴 구간까지만 된다.
- 판매자 승인 여부는 결정이 필요하다. 권장은 자동이다.

### 써보기 종료와 거래 완료
- 끝나기 하루 전에 채팅 시스템 메시지로 알린다.
- 구매자는 "살게요"와 "돌려보낼게요" 중 하나를 누른다. 아무것도 누르지 않으면 이미 정한 규칙대로 구매로 처리한다.
- 반납은 구매자가 송장을 입력하고, 판매자가 구성품 체크리스트(이미 등록된 구성품)로 확인한 뒤 완료한다.

### 정산
- 정산일은 구매확정이나 반납 확인 후 D+N일로 한다. N은 결정이 필요하다.
- 판매자 정산 계좌는 민감 정보다. 암호화해 저장하고 본인과 운영자만 볼 수 있게 한다.
- 판매자 정산 내역 화면에는 판매가, 수수료 3%, 체험비, 입금액, 상태를 보여 준다.
- 운영자가 송금한 뒤 "정산 완료"를 누르는 방식으로 처리한다.

### 카카오 공유
- 지금 바로 할 수 있는 방법: 휴대폰 기본 공유창(카카오톡이 포함되어 있음)과 링크 복사. 키가 필요 없다.
- 카카오톡 전용 카드 공유(사진·가격 미리보기)는 카카오 개발자 앱 등록과 도메인 등록이 필요하다. 사용자 작업이다.
- 링크 미리보기(사진·제목·가격)를 위해 상품 상세에 공유용 미리보기 정보를 넣는다.

## 6. 권장 순서
1. 공유: 다른 작업과 무관해 바로 할 수 있다.
2. 구매·무통장 결제와 배송지
3. 써보기 시작·연장·종료·거래 완료
4. 후기
5. 등급과 판매자 채널
6. 정산 내역
7. 써보니 평균 금액(데이터가 쌓이는 대로)

## 7. 결정 필요
1. 등급 단계별 기준 수치(위 예시대로 갈지)
2. 써보니 평균 금액이 체험비 평균이 맞는지
3. 연장할 때 판매자 승인을 받을지(권장: 자동)
4. 정산일 D+N에서 N
5. 무통장 결제 운영 전 법률 확인 방법(베타를 실제 돈으로 할지)
6. 카카오 개발자 앱 등록 여부(전용 카드 공유가 필요하면)

## 추가 아이디어 (사용자 보충 요청: 등급 예시, 써보니 후기, 평균 금액 노출. 확정 아님)

### 등급 이름 안
- A. 성장형: 써린이 → 하수 → 중수 → 고수 → 써신(써보기의 신). 각 단계를 Lv.1~3으로 나눠 모두 15레벨.
- B. 별 테마(써보기 스타와 연결): 새싹 → 브론즈 → 실버 → 골드 → 써스타
- C. 판매자 전용 이름: 새내기 → 믿음 → 단골 → 명품 판매자
- 권장: A. 구매자와 판매자는 같은 이름을 쓰고 아이콘(🛍 구매 / 🏪 판매)으로 구분한다.

### 경험치 예시
| 항목 | 점수 |
|---|---|
| 거래 완료 | +10 |
| 써보기 완료(사거나 돌려보냄) | +15. 써보기를 장려한다 |
| 받은 점수 9~10점 | +5 |
| 받은 점수 7~8점 | +3 |
| 받은 점수 4점 이하 | -5 |
| 후기 작성 | +2 |
| 판매자가 24시간 안에 발송 | +3 |
| 구매자가 반납 기한을 지킴 | +3 |
| 확정 분쟁 | -30 |

### 배지 (등급과 별도)
- 칼답: 채팅 응답이 빠름
- 설명 그대로: 설명 일치 문구 90% 이상
- 깔끔 반납러: 반납 상태가 좋은 구매자
- 써보기 장인: 써보기 10회 이상

### 써보니 후기 (써보기를 쓴 사람만)
- 필수
  - 써보니 경험 점수 1~10
  - 결과: 써보고 샀어요 / 써보고 돌려보냈어요
  - 문구 1개 이상
- 문구 예시
  - 산 경우: 실물이 사진과 같아요, 설명 그대로예요, 써보길 잘했어요, 상태가 생각보다 좋아요, 체험비가 합리적이에요, 기간이 넉넉했어요, 구성품이 다 있었어요
  - 돌려보낸 경우: 사이즈·핏이 안 맞았어요, 생각한 용도와 달라요, 그래도 써봐서 다행이에요, 반납이 간편했어요
- "써보고 알게 된 점" 한 줄: 예) 배터리가 하루 버텨요. 같은 모델을 사려는 다음 사람에게 가장 쓸모 있는 정보다.
- 후기에 "써보니 인증 · 48시간 써봄" 표시를 붙인다.
- 써보니 후기를 모델별로 모아 보여 준다: 상품 상세에 "이 모델 써본 사람들의 한마디". 판매자가 바뀌어도 모델 정보가 쌓인다.

### 써보니 평균 금액 노출
- 써보니 시세: 같은 모델이 써보니에서 실제로 팔린 가격의 평균(최근 90일, 3건 이상). 예) "이 모델 써보니 시세 52만원 · 최근 거래 8건"
- 체험비: 상품마다 가격이 달라 금액끼리 비교하기 어렵다. 그래서 체험비율(하루 체험비 ÷ 상품가)로 비교한다. 예) "노트북 평균 하루 0.8%"
- 상품 상세 배지: "평균보다 체험비 300원 저렴", "시세보다 3만원 저렴"
- 판매자 채널: 이 판매자의 평균 체험비율과 써본 사람 대비 구매 비율
- 기준 순서: 모델 → 상품군 → 데이터 부족 표시. 건수와 기간을 함께 적는다.

## 등급 아이디어 심화 (사용자 요청 "더 고민해봐", 확정 아님)

### 핵심 방향
1. 구매자와 판매자는 이름 체계부터 따로 둔다. 구매자는 써보는 실력이 느는 감별사 계열, 판매자는 가게가 커지는 계열이다.
2. 승급은 경험치만 쌓아서 되는 방식이 아니라 미션을 달성하는 방식으로 한다. 써보니가 원하는 행동(써보기, 쓸모 있는 후기, 기한 지키기)을 하면 오르게 만든다.
3. 등급 이름은 활동량을, 별점 색은 신뢰를 나타내는 두 축으로 보여 준다. 예) "감별사 ★9.2". 활동은 많은데 평이 나쁜 사람이 높아 보이지 않게 한다.
4. 등급마다 실제 혜택을 붙인다. 이름만 바뀌면 오를 이유가 없다.

### 구매자 등급 (감별사 계열)
| 등급 | 승급 미션 예시 | 혜택 예시 |
|---|---|---|
| 🐣 써린이 | 가입 | - |
| 🥄 찍먹러 | 첫 써보기 또는 첫 거래 완료 | 써보기 제안 하루 한도 증가 |
| 🎒 체험러 | 거래 5회 완료, 반납 기한 100% 준수 | 판매자에게 "믿을 수 있는 구매자" 표시 |
| 🔍 감별사 | 거래 15회, 써보니 후기 '도움돼요' 10개 | 연장 1회 수수료 면제 |
| 👑 써신 | 거래 40회, 평균 9점 이상, 분쟁 0 | 써보기 신청 우선, 써보니 체험단 초대 |

### 판매자 등급 (가게 계열)
| 등급 | 승급 미션 예시 | 혜택 예시 |
|---|---|---|
| 🧺 좌판 | 첫 상품 등록 | - |
| 🏠 가게 | 거래 3회 완료 | - |
| 🏪 상점 | 거래 10회, 평균 8점 이상 | 정산 하루 빠르게 |
| 🏯 명가 | 거래 30회, 평균 9점, "설명 그대로" 90% 이상 | 수수료 할인(예: 2.5%) |
| 💎 써보니 명가 | 명가 조건 + 최근 90일 활동 + 판매 상품의 절반 이상 써보기 허용 | 써보고 사는 상품 칸 우선 노출 |

- 최고 등급에 "써보기 허용 비율"을 넣으면, 판매자가 써보기를 열수록 유리해진다. 써보니 서비스의 목적과 맞는다.

### 그 밖의 장치
- 진행 막대: MY에 "감별사까지 거래 3번, 도움돼요 4개 남음"을 보여 준다.
- 도움돼요 버튼: 써보니 후기에 단다. 쓸모 있는 후기를 쓴 사람이 오르게 해서 후기 품질을 높인다.
- 전문 분야 배지: 한 상품군에서 10건 이상 완료하면 "신발 전문"처럼 자동으로 붙는다. 현재 판매 상품의 대부분이 신발·의류다.
- 새 판매자 안심: 좌판·가게 단계의 첫 3거래에는 "써보니가 함께 확인해요"를 표시하고 운영자가 살핀다. 처음 시작하는 판매자의 신뢰 부족을 메운다.
- 활동 유지: 판매자 최고 등급은 최근 90일 활동이 있어야 유지된다. 구매자 등급은 내려가지 않는다.
- 경고와 강등: 반납 지연이나 연락 두절은 경고 1회, 경고가 2회면 한 단계 내린다. 경고 표시는 거래 상대에게만 보인다.
- 공개 범위: 판매자 등급은 모두에게 보인다. 구매자 등급은 제안·주문을 받은 판매자에게만 보인다.
- 외부 실적: 당근 후기 64개 같은 외부 실적은 등급에 넣지 않는다. 확인할 수 없는 데이터라서 "외부 후기" 링크로만 둔다.
- 시작 시점: 실제 완료 거래가 생겨야 계산한다. 출시 때는 모두 써린이·좌판에서 시작한다.

### 대안 이름 (사용자 예시 유지형)
- 하나의 사다리: 써린이 → 하수 → 중수 → 고수 → 써신. 구매자와 판매자는 아이콘으로 구분한다.
- 써린이는 꼭 남긴다. 써보니만의 이름이라 기억하기 쉽다.
