# 써보니 중고거래형 UI 시안 v0.2

## 작업 결과

기존 Style 2의 색상과 둥근 카드 감각은 유지하되, 화면 중심을 설명 카드에서 중고상품으로 바꿨다. 홈 피드, 상품 상세, 판매하기, 찜, MY 다섯 화면에 상품 사진, 가격, 상태, 지역·등록시간, 판매자, 거래 의향을 전면 배치했다.

시안 원본은 `E:\PROJECTS\04_써보니\visualizations\sseoboni-marketplace-mockup-v0.2.html`, 채팅 표시용 이미지는 `E:\PROJECTS\04_써보니\visualizations\sseoboni-marketplace-mockup-v0.2.png`이다. 가격과 상품 정보는 시안용 예시이며 실제 거래 데이터가 아니다.

## 작업 지시 요약

목표는 참고 이미지의 강한 타이포와 색상 리듬을 유지하면서도 써보니가 중고상품을 사고팔고 필요하면 먼저 써보는 서비스라는 점을 첫 화면에서 인식시키는 것이었다. 기존 시안은 보존하고 새 버전만 추가했으며 앱 코드·DB·배포·외부 공개는 변경하지 않았다.

## 검증

- 모바일 화면 5개와 로컬 이미지 참조 13개를 확인했다.
- 남은 템플릿 마커는 0개다.
- Chrome headless로 1500×1900 PNG를 렌더링하고 화면 잘림과 이미지 로딩을 육안 확인했다.
- 사용된 세 개의 로컬 이미지 파일 존재를 확인했다.
