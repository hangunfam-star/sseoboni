## 2. 새로 만든 기능과 고친 검수 결함

- `POST /api/intents`: 써보고 싶어요·사고 싶어요 의향만 이벤트(`CLICK_TRY_WANT`/`CLICK_BUY_WANT`)로 기록. 같은 사람·상품·종류는 1회만
- `PATCH /api/listings/[id]`: 판매자 본인만 ACTIVE/HIDDEN/SOLD 변경
- 판매자 써보기 의향: 등록 시 `SELLER_TRY_YES/CONDITIONAL/NO` 이벤트, `SELLER_LISTING_COMPLETE` 이벤트
- C-01 입력 검증: 가격 1,000원~1억 원 정수, 제목 2~60자, 설명 2,000자, 등급 S/A/B/C만, 수요 가격 0 이상·최소≤최대
- C-02: 잘못된 JSON·없는 상품/모델에 500 대신 400/404
- D-01: 숨김·판매완료 상품은 타인에게 API 404, 상세는 "판매가 종료된 상품" 안내
- E-01: 로그인 사용자의 같은 상품 30분 안 재조회는 1회로 기록, 판매자 본인 조회 제외, 상세 API의 이중 조회 기록 제거, 찜 해제 이벤트 추가, 같은 수요 재등록은 새 행 없이 수정
- E-02: 찜·수요·등록의 본체 저장과 이벤트 저장을 트랜잭션으로 묶음
- 화면 수요 숫자는 중복 제거한 실제 인원이며 3명 이상일 때만 숫자로 표시(§8 결정 3 권고값)
