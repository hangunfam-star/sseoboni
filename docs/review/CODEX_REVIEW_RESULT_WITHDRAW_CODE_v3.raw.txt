## 2. 새로 확인된 결함

### 보통 · ⓐⓑⓒ · 통신 예외가 나면 탈퇴 버튼이 영구적으로 잠김

- 증상: `fetch()`가 연결 끊김·서버 재시작 등으로 예외를 던지면 화면은 계속 `탈퇴 처리 중…` 상태로 남고 오류 안내나 재시도가 불가능합니다.
- 원인: `pending=true` 이후 `fetch()`와 응답 처리가 `try/catch/finally`로 보호되지 않았습니다. [WithdrawForm.tsx](</E:/PROJECTS/04_써보니/app/src/app/me/account/WithdrawForm.tsx:16>)
- 바뀌어야 할 동작:
  - 수정 전: 통신 예외 → 처리 중 상태 고정·미처리 Promise
  - 수정 후: 통신 예외 → 상태 확인 안내·`pending=false`·재시도 가능
- 수정안: `fetch`와 JSON 처리를 `try/catch/finally`로 감싸고, 응답을 받지 못한 경우 “결과를 확인하지 못했어요. 새로고침 후 다시 확인해 주세요.”처럼 결과 불확실성을 숨기지 않는 안내를 표시합니다.
- 검증안: Playwright에서 요청 중단 또는 연결 실패를 주입해 오류 표시, 버튼 재활성화, 재시도 가능 여부를 확인합니다.
- 이 결함은 마지막 화면 이동 수정이 직접 만든 것은 아니지만, 이번 전수 검수에서 새로 확인됐습니다.
